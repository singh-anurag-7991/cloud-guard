01 / Cloud cost & security

Cloud Guard

AWS waste finder

Connects to an AWS account through a read-only IAM role and reports what is costing money for no reason — unattached volumes, idle Elastic IPs, stale snapshots, gp2 volumes that should be gp3. Every finding is priced from AWS list prices and ships with the CLI command that fixes it.

Live right now running on this server, scanning real accounts

02 / API defence

Shield

Distributed rate limiter as a service

A rate-limiting service in Go that protects APIs from abuse, brute-force and overload. Four algorithms — token bucket, leaky bucket, fixed window and sliding log — configurable per API key and per endpoint, returning correct 429s with X-RateLimit-* headers.

~55K req/s token bucket, benchmarked locally
